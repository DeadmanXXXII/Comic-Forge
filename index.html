COMIC_FORGE

Your API keys are stored only in this browser (localStorage) and sent directly from your browser to the provider you choose. They are never sent anywhere else, including to us.

Build your comic from JSON (issues → pages → panels) or from Markdown in the same script format your build pipeline's source file already uses. Either path ends up as the same JSON below — "Apply to Panels tab" always reads from the JSON box.

The example is the exact JSON structure behind the rain-soaked street and hooded-figure panels shown in the app's own screenshots — good reference for how specific a panel description needs to be to come out on-theme.
Parses the same script format as Anonymous_Heroes_Full_Series_Script.md: one ## ISSUE N: "Title" heading per issue, **Page N** and - **Panel N** — description lines, with *Narration:*, *Dialogue (Speaker):*, *Thought (Speaker):*, *Text on screen:*, *Caption:*, and *Image Prompt:* as sub-bullets. Two extra conventions this app adds on top: a **Cover** block right after the issue heading (*Image Prompt:* / *Subtitle:*), and marking a page as a full-bleed splash with **Page N (HERO)** (*Image Prompt:* / *Caption:* instead of panels). Everything before the first ## ISSUE heading (series bible, act headers) is ignored, so you can paste your whole script file in as-is.
No story loaded — go to Story Data tab first.

Builds a printable page from whatever panels currently have art, then opens your browser's print dialog — choose "Save as PDF" there for a PDF file.

Comic Forge — runs entirely in your browser. No data leaves your device except direct calls to the AI provider you configure, using your own key.
